# META CAMPAIGN AUTOMATOR — páginas legais

Arquivos:
- index.html
- privacy.html
- terms.html
- data-deletion.html

Antes de publicar:
1. Substitua `SEU_EMAIL_DE_CONTATO_AQUI` pelo e-mail que você deseja tornar público.
2. Publique a pasta em um host HTTPS.
3. Use as URLs públicas correspondentes nos campos da Meta.

Exemplo:
- https://SEU-SITE/privacy.html
- https://SEU-SITE/terms.html
- https://SEU-SITE/data-deletion.html

Nenhum token, senha, Page ID, Ad Account ID ou chave secreta foi incluído nestes arquivos.
